# StuckDownloadGuard（下载守卫）

监控下载任务，长时间无速度则降级排至队尾重试，重试无效则切换下载源/清理。

## 功能

- 周期监控 qBittorrent / Transmission 中带 MoviePilot 标签的种子，识别「下载中但无速度」的卡顿任务。
- **异常态立即清理**：`error` / `missingFiles` / `unknown` 僵尸种子一经发现立即停止并清理（订阅来源顺带重新搜索），不进入重试观察窗口。
- **按有无做种人分流**：
  - 无做种人（`num_seeds == 0`）：直接尝试换源/清理，跳过 30min×重试 的空等；
  - 有做种人：先降级排至队尾重试，达重试上限后再换源 → 失败才清理。
- 换源：订阅来源触发订阅链重搜；非订阅来源按候选索引器重搜更优种子并替换。
- 不误伤：已完成做种（stoppedup 100%）、暂停、排队中的任务。

## 配置

| 配置项 | 说明 |
|---|---|
| 启用插件 | 开关 |
| 发送通知 | 接管动作时推送 MoviePilot 消息 |
| 监控周期 | 定时检查 Cron |
| 无速度判定时长 | 持续无速度多久判定卡顿（分钟） |
| 重试次数 | 降级排尾重试上限 |
| 仅监控订阅下载 | 开启后只处理来源为订阅的任务 |

## 使用说明

1. 启用插件并按需调整监控周期与阈值；默认配置适合大多数场景。
2. 插件仅处理带 MoviePilot 标签（`TORRENT_TAG`）的种子。
3. 注意：本插件只管理 qBittorrent / Transmission 种子；LunaTVSource 的 m3u8 直下通道由其自身换源机制负责。

## 版本
